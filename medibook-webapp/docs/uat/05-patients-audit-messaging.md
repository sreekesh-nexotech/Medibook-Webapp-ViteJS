### Faults found (NEW unless an existing blocker ID is cited)

- F1. MRN not URL-encoded in the detail link — `PatientsScreen.tsx:102-103` — an MRN containing `/ ? # %` (the format only validates `{…}` tokens, `numbering.py:51-68`) opens NotFound or a different record — fix frontend: `encodeURIComponent(mrn)` in a `hospitalPatientPath()` helper next to `hospitalBookForPatientPath` (`src/app/router/paths.ts:192`).
- F2. Permission gating inconsistent — "Book appointment" row icon (`PatientsScreen.tsx:253-259`) and the empty-state "Add patient" (`:157-158`) are ungated; the detail screen gates the same booking action (`PatientDetailScreen.tsx:184`) — a role without the permission reaches ForbiddenScreen / a 403 — fix frontend (`Can`).
- F3. Visits column issues one request per row — PAT-01.
- F4. Add form cannot capture a structured address (city / state / pincode) even though the backend stores it, CLAUDE.md §7 requires it and the detail page displays it — `PatientModal.tsx:208-215` — fix frontend (add fields; `pincode` must match `^\d{6}$`).
- F5. D-16 auto-link result is silent: the desk is never told the record was linked to a Medibook account, or that a new dependant was created under someone's account and they were notified — `PatientModal.tsx:112-115` — fix frontend (parse `link_method`, show it on the toast and in the profile).
- F6. Registration and edit only accept a 10-digit Indian mobile (`validate.ts:46-54`, `maxLength={10}` at `PatientModal.tsx:176`); the backend accepts any E.164 — patients with a foreign number cannot be registered with it, and editing a record that already has one fails until the phone is replaced (`displayPhone` keeps the full `+1…`) — fix frontend (country code or E.164 input).

### Needs API integration or rework

- R1. Delete / deactivate patient — not built — wire `DELETE /api/v1/hospital/patients/{id}` (If-Match; `patients.del`, admin by seed; 202 `{request_id}` when `patient_edit_requires_approval`, else 204; 409 `PERSON_HAS_APPOINTMENTS` on active bookings).
- R2. Legacy MRN (O-05) — never displayed or settable — add to Add/Edit (`legacy_mrn` already accepted) and show it as a secondary number on the detail page.
- R3. Visits column — needs `completed_visits` on list rows (PAT-01).
