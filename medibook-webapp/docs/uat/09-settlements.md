## Screens covered

- SettlementsScreen (hospital "Billing & Settlements") — route `/:role/settlements` — file `web:src/features/settlements/presentation/screens/SettlementsScreen.tsx` — gate: `RequireAdmin` → `RequirePermission perm="Billing & Settlements.view"` (`web:src/app/router/routes.tsx:134`, `RequireAdmin.tsx:24`). Backend: every read needs `billing_settlements.view`; plan-change list + create need `billing_settlements.edit` (`api:subscriptions/views/hospital_plan_change_requests.py:21`). Roles holding them: admin (all) and accountant (`view`,`edit`) (`api:core/seeds/v1.py:72,96`); receptionist / dept_front_desk get `ForbiddenScreen`. Accountant lands on the `/receptionist/...` shell (`web:src/features/auth/application/store/auth.roles.ts:16-18`); sidebar entry shown by `canViewModule` (`web:src/app/layouts/HospitalSidebar.tsx:55`). Two tabs only: **Settlements** (KPIs, periods table, period drawer) and **Plan & Billing**. There is **no Payouts tab and no Statements tab**: the payout and the statement are shown inside the period drawer; `/hospital/settlements/payouts[/{id}]` is never called.
- `/:role/billing` — deliberately not routed (`web:src/app/router/routes.tsx:80-83`); `hospitalBillingPath()` (`paths.ts:228`) has **zero call sites** (grep) → no link lands on NotFound. Nothing to fix.
- OpsSettlementsScreen ("Hospital Settlements") — route `/ops/settlements` — file `web:src/features/ops-settlements/presentation/screens/OpsSettlementsScreen.tsx` — gate: `RequireOpsView` → `settlements.view` (`web:src/app/router/opsAccess.ts:21`); create/approve/release buttons behind `CanOps perm="settlements.edit"`. Backend: GETs `settlements.view`, POSTs `settlements.edit`. Roles: owner, ops_manager, finance hold both; read_only holds `view` only; support/compliance hold neither (`api:core/seeds/v1.py:117-160`). No four-eyes on the backend (see F11).
- OpsSettlementsHospitalCard — embedded in the ops hospital profile (`/ops/hospitals/:id`) — file `web:src/features/ops-settlements/presentation/components/OpsSettlementsHospitalCard.tsx`.
