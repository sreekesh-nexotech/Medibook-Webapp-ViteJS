### Faults found (NEW unless an existing blocker ID is cited)

- F1. Topbar fires `GET /platform/dashboard` on every ops screen for roles without `dashboard.view` (finance, support,
  compliance) → 403 on every page load, bell silently empty — evidence `src/app/layouts/OpsTopbar.tsx:133`,
  `useOpsDashboardQuery.ts:12-17` (no `enabled`); be `views/platform_dashboard.py:12` — impact: noisy 403s/audit noise, those

  queries next to it, which need `plans.view`/`settlements.view`; not verified further — shell scope).

  be `services/platform_dashboard.py:56-60` — impact: ops cannot tell which hospital without clicking — fix (backend): include
  `hospital__name` in the `stale_cash` values().
- F3. Alerts naming >3 hospitals collapse into "+N more" plain text with no way to reach the rest — evidence
  `opsDashboardFormat.ts:82-87` — fix (frontend).

### Faults found (NEW unless an existing blocker ID is cited)

- F4. "Booking Success Rate" and "Cancellation Rate" divide counts from different cohorts (bookings by `created_at`,
  completed/cancelled/no-show by their own timestamps) — evidence `OpsAnalyticsScreen.tsx:89-105`, be `rollup.py:61-67`
  — impact: ratios can exceed 100% on short windows / mislead — fix (frontend relabel "Completed ÷ bookings made" or
  backend cohort metric).
- F4b. Usage rollup counts abandoned online checkouts (created `pending_payment`, expired by the 60 s sweeper) as
  bookings AND as cancellations; the platform reports exclude them (`N_BOOKING`, be `reports/services/specs.py`) — so
  Analytics and Reports disagree and the cancellation rate is inflated — evidence be `analytics/services/rollup.py:60-65`,
  `appointments/services/cancellation.py:239-248` — fix (backend rollup; related to DASH-01 for the hospital dashboard,
  but this is the platform rollup → NEW). The ops dashboard KPI "Bookings (30 days)" has the same definition
  (be `services/platform_dashboard.py:124-126`).
- F5. Client-side CSV exports do not neutralise spreadsheet formulas (`=`, `+`, `-`, `@` at cell start; hospital names are
  free text) — evidence `src/shared/lib/download.ts` `csvCell` — impact: CSV injection when opened in Excel — fix
  (frontend shared helper; applies to every client CSV in this group).
